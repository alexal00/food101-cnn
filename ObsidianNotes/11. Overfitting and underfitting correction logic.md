| Observed behavior                                  | Likely diagnosis                  | Correction                                                                                           |
| -------------------------------------------------- | --------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Training accuracy high, validation accuracy low    | Overfitting                       | Increase dropout, weight decay, or augmentation; freeze more layers; reduce model size.              |
| Training and validation accuracy both low          | Underfitting                      | Train longer, increase model capacity, check learning rate, check preprocessing, verify labels.      |
| Validation loss increases while accuracy stagnates | Overconfidence / poor calibration | Add or increase label smoothing, evaluate calibration, consider temperature scaling.                 |
| Specific classes have poor accuracy                | Class-specific weakness           | Inspect confusion matrix, review examples, add targeted augmentation, report top-5 behavior.         |
| Inference result differs from validation behavior  | Preprocessing mismatch            | Verify inference transform equals validation transform.                                              |
| Model too slow locally                             | Deployment bottleneck             | Use EfficientNet-B0 or MobileNetV3, reduce batch size, export optimized model.                       |
| MPS memory errors                                  | Local memory constraint           | Reduce batch size, disable cache-in-memory, use gradient accumulation, train larger models in cloud. |
