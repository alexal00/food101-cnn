TensorBoard is used for local experiment tracking. PyTorch provides `tensorboard.utils.tansorboard`, which can log scalars, images, histograms, graphs, and embedding fro visualization.

Log:
```text
train loss
validation loss
top-1 accuracy
top-5 accuracy
macro F1
learning rate
confusion matrix image
misclassified sample grid
calibration plots
```
Recommended run naming:
```text
outputs/tensorboard/
├── baseline_cnn_subset10/
├── efficientnet_b0_subset10/
├── efficientnet_b0_full101/
├── resnet50_full101/
└── convnext_tiny_full101/
```
