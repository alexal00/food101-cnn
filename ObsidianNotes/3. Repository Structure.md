The final deliverable is contained inside `notebooks/`, but the code does not lie entirely inside the notebook. The final notebooks acts as a report and experiment driver; reusable logic is placed inside the python modules.

This structure ensures

| Block              | Reason                                                                               |
| ------------------ | ------------------------------------------------------------------------------------ |
| `notebooks/`       | Contains the final course narrative, figures, tables, and conclusions.               |
| `src/food101_cnn/` | Keeps implementation reusable and testable.                                          |
| `configs/`         | Centralizes hyperparameters and prevents hidden notebook state.                      |
| `scripts/`         | Enables repeatable CLI execution outside the notebook.                               |
| `tests/`           | Verifies that data loading, transforms, model outputs, and metrics behave correctly. |
| `outputs/`         | Separates generated artifacts from source code.                                      |
