Project should include two model families:
1. Custom CNN from scratch
2. Transfer-learning CNNs
## 5.1 Model A: Custom CNN from scratch
The recommended architecture for the baseline CNN is:
```text
Input: 3 × 224 × 224

Block 1:
    Conv2d(3 → 32, kernel=3, padding=1)
    BatchNorm2d
    ReLU
    Conv2d(32 → 32, kernel=3, padding=1)
    BatchNorm2d
    ReLU
    MaxPool2d

Block 2:
    Conv2d(32 → 64)
    BatchNorm2d
    ReLU
    Conv2d(64 → 64)
    BatchNorm2d
    ReLU
    MaxPool2d

Block 3:
    Conv2d(64 → 128)
    BatchNorm2d
    ReLU
    Conv2d(128 → 128)
    BatchNorm2d
    ReLU
    MaxPool2d

Block 4:
    Conv2d(128 → 256)
    BatchNorm2d
    ReLU
    AdaptiveAvgPool2d(1)

Classifier:
    Flatten
    Dropout
    Linear(256 → 101)
```

This model ensures both the computational limits are satisfied and the CNN complexity.

|Component|Reason|
|---|---|
|Small 3×3 convolutions|Standard local feature extraction with limited parameter growth.|
|Batch normalization|Stabilizes activation distributions and improves optimization.|
|ReLU|Simple, computationally efficient nonlinearity.|
|Max pooling|Reduces spatial resolution while increasing receptive field.|
|Adaptive average pooling|Allows the classifier to receive a fixed-size feature vector.|
|Dropout|Reduces overfitting in the classifier head.|
This model will most-likely underperform the transfer learning on the full Food-101, but provides a transparent baseline.

## 5.2 Model B: Transfer Learning
Recommended candidates:

|Backbone|Role|Reason|
|---|---|---|
|EfficientNet-B0|Primary local baseline|Good accuracy/efficiency compromise for 8 GB unified memory.|
|ResNet-50|Classical reference baseline|Widely understood, easy to explain, robust comparison model.|
|ConvNeXt-Tiny|Stronger modern CNN candidate|Useful for maximum accuracy comparison if memory allows.|
|EfficientNet-B2 or B3|Optional cloud experiment|Better accuracy potential, but heavier for local 8 GB training.|
### Recommended final backbone
The main local model should be, considering the current computational power:
```text
EfficientNet-B0 pretrained on ImageNet
→ replace classifier head with Food-101 classifier
→ train head
→ unfreeze upper blocks
→ fine-tune with low learning rate
```

Which should be compared against:
```text
ResNet-50
ConvNeXt-Tiny
```
