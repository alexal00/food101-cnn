The project is designed as a course deliverable CNN project for Food-101.
Main goals are:
1. **Pedagogical goal**: explain how a CNN is built, trained, diagnosed, corrected and evaluated
2. **Performance goal**: obtain a reasonably accurate Food-101 classifier, prioritizing top-5 accuracy

Implementation is to be: **Pytorch-based**, notebook-first, locally runnable but with optional cloud training for heavier experiments. It will use the original Food-101 images, preserve official train/test split, include automatic download, image validation, cached 224x224 preprocessing, TensorBoard logging, automated tests, CLI inference, and final export to `.pt` or `.onnx`.

## Dataset information
Food-101 contains 101 classes and 1000 images per class; 750 training and 250 test. The training set intentionally contains some noisys labels/images, which justifies validation diagnostics, label smoothing, and misclassification analysis.

## 1. Global design strategy
The objective is a stagged CNN development pipeline:
```text
Small subset experiment
→ CNN from scratch baseline
→ transfer-learning baseline
→ multi-backbone comparison
→ full 101-class training
→ final evaluation
→ Grad-CAM / calibration / latency / inference export
```
Thus ensuring pipeline correctness from model performance.
First goal is to prove that data loading, transforms, labels, metrics, logging, checkpointing, and inference work. Only after that the project should scale to all 101 classes.
