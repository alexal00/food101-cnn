Mandatory metrics are:
```text
top-1 accuracy
top-5 accuracy
macro F1
per-class accuracy
confusion matrix
loss curves
calibration
misclassified examples
inference latency
```

The primary metric is: **validation top-5 accuracy**
Reason: Food classification has natural ambiguity; visually similar dishes can be confused. Top-5 accuracy better measures whether the correct food appears among plausible predictions.

Secondary metrics are included since:

| Metric             | Why it is needed                                 |
| ------------------ | ------------------------------------------------ |
| Top-1 accuracy     | Standard classification score.                   |
| Macro F1           | Detects poor performance on specific classes.    |
| Per-class accuracy | Identifies systematically weak classes.          |
| Confusion matrix   | Shows semantic confusions between foods.         |
| Calibration        | Checks whether confidence values are meaningful. |
| Latency            | Verifies local usability.                        |
The calibration report includes:
```text
reliability diagram
expected calibration error
confidence histogram
accuracy vs confidence bins
```

Since a model can have stable accuracy while becoming more overconfident. Calibration analysis is the right diagnostic when validation loss increases while accuracy stagnates.

The misclassification galley includes:
Saved images such as
```text
true label
predicted top-1
top-5 probabilities
image path
confidence
```

Generating figures like
```text
outputs/misclassified/top_confident_errors/
outputs/misclassified/low_confidence_errors/
outputs/misclassified/classwise_errors/
```
