Project should validate CLI inference through:
```text
scripts/predict.py
```

The expected behaviour is:
```text
Input:
    image path or folder path

Output:
    top-k predicted classes
    probabilities
    confidence decision
    optional CSV report
```

The example command is:
```bash
python scripts/predict.py \
  --config configs/efficientnet_b0.yaml \
  --checkpoint outputs/checkpoints/best_model.pt \
  --input data/processed/test/apple_pie \
  --top-k 5 \
  --threshold 0.40
```

An additional low confidence rejection is included as follows:
```text
if max_probability < threshold:
    return "uncertain prediction"
else:
    return top-k predictions
```
This provides an uncertainty flag.

Batch inference over a folder is supported.
